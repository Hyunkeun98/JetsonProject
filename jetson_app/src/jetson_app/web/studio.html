1. 설정

선택태그종류대기잡음범위/잡음판정과 이유

추천 태그는 평소 조용하고 값의 범위가 넓은 신호(예: 서보 위치)입니다. 추천을 따르면 충격 같은 순간적인 이탈을 잡습니다.

2. 정상 데이터 수집

브로커에 연결해 정상 운전 데이터를 모읍니다. 정상 사이클이 여러 번(가능하면 10회 이상) 들어가야 기준이 안정됩니다.

3. 학습

수집한 정상 데이터로 신호별 잡음 크기와 알람 기준을 계산합니다. 몇 초 걸립니다.
