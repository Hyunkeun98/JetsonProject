1. 연결

사이클 수를 정확히 세려면 사이클 시작 신호나 카운터가 있는 토픽도 같이 적으세요. 없으면 움직임의 반복으로 추정합니다.

2. 살펴보기

토픽으로 데이터가 들어오는지만 확인합니다. 아무것도 저장하지 않고, 끝내면 연결을 끊습니다(5분 뒤 자동 종료).


  






  
3. 전체 수집

  
정상으로 운전하는 동안 들어오는 데이터를 원본 그대로 모읍니다. 정상 사이클이 10회 이상 들어가야 기준이 안정됩니다.
    수집하는 동안 축이 움직이는 사이클이 들어가야 태그를 추천할 수 있습니다(멈춘 상태만 모으면 추천이 비어 나옵니다).
    이상 상황은 섞이지 않게 하세요. 수집은 1GB에 닿으면 자동으로 끝납니다.

  
  
  
  

  

  
  
  





  
4. 태그 추천

  
수집한 데이터로 점수에 쓸 태그를 추천합니다. 추천 태그는 평소 조용하고 값의 범위가 넓은 신호(예: 서보 위치)입니다.

  
  

    
선택태그종류대기잡음범위/잡음판정과 이유

  

  
  
  






  
5. 학습

  
고른 태그로 신호별 잡음 크기와 알람 기준을 계산합니다. 몇 초에서 몇 분 걸립니다.
